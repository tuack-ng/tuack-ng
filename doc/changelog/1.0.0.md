## 🚀 新增功能与优化

- **【渲染】支持完整的 CommonMark 及 CNOI 拓展语法，支持图片嵌入、附加选项、HTML 风格注释、模板清单**
- **【渲染】基于 MiniJinja 的模板表达式与函数机制，支持 `sample()`、`sample_file()`、`cases`、`data_cases`、`sample_cases` 等上下文函数**
- **【工程】Tuack 风格工程目录，支持生成工程文件夹、自动填入名称、可选自定义 IO 文件、自动搜索题目/样例/代码**
- **【命令行】统一加载配置文件，支持 Shell 自动补全、自定义 Panic 信息、输出诊断信息、配置警告树形化等**
- **【测试】实现了测试功能，支持 CSV 导出、Subtask 测评、测试样例；重构编译运行逻辑，支持解释型语言；异步检测时间空间**
- **【测评】支持 SPJ 和标程返回部分分数（PC）；支持交互题出题流程；输入输出格式支持标准输入输出**
- **【数据生成】`tuack-ng dmk` 批量造数据，支持细粒度生成模式、样例单独指定数据生成器**
- **【配置】实现了类似于 Tuack 的配置文件结构；`tuack-ng conf` 批量修改配置文件**
- **【跨平台】适配了 Windows 与 Nix**
- **【导出】支持 Arbiter 和 Lemon 导出**
- **【构建】支持了 deb，AUR；Windows 使用 Zip 格式分发**
- **【UI】更友好的人机界面，包括进度条，带颜色显示等**
- 【模板】添加了 noi-dark 模板，即 noi 模板的暗色模式
